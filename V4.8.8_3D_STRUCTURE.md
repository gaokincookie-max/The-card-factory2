# v4.8.8 3D battlefield refactor

- `src/battle-3d-layout.js`: aspect-dependent camera profiles, board bounds, slot positions, rotated-screen coordinate conversion. Pure functions for regression testing.
- `src/battle-card-texture.js`: 5:7 canvas card drawing, preserving the existing appearance and artwork behavior.
- `src/battle-3d.js`: Three.js scene lifecycle, texture cache, render loop, raycasting, disposal, and delegation to pure helpers.
- Rules, battle state, display settings, CSS and responsive dimensions are unchanged.
- `tests/battle-3d-modules.test.mjs`: validates aspect profiles, board geometry, placement and pointer normalization.
- Requires real-device testing of pinch/drag and CSS-rotated portrait Safari; no visual browser test is claimed.
