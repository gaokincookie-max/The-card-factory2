# Factory Card Game v0.4 — 工場UI改修

GitHub Pages で公開可能な静的Webゲームの試作版です。フォルダをそのまま公開、または `index.html` をブラウザで開いて利用してください。

## 操作
- 工場盤面を最大表示、施設をタップすると左右2欄のポップアップでレシピ・在庫・製造状況が見られます。
- 下部の建築メニューから施設を選択→盤面タップ→施設の上に表示する ✓ / ↻ / × を使います。
- レシピ一覧は資材のあるものが強調され、タップで設定できます。長押しはレシピ情報を表示します。
- 施設詳細から ⓘ で説明、撤去ボタンで確認後撤去できます。
- 中央の2×2出荷区画、または上部の出荷設定から、境界線をタップして分割を調整できます。
- ベルト敷設は始点・終点をタップします。ベルト撤去は工具切替後にマスをタップします。
- 採集施設は四辺から順番に排出を試みます。
- スマートフォンでは横画面を推奨し、縦画面には回転の案内を表示します。

## 今回の範囲 / 注意点
工業画面のUI変更を中心にしています。戦闘画面・CPU戦は未実装です。製造・ベルト・倉庫等の既存ゲームエンジンは引き継いでいますが、長時間のブラウザ実機テストは未完了です。カードの長押し詳細は現状レシピの基本情報のみです。
強化と生産数値はv0.3の暫定値です。


## v0.5 共通カードUI
- 手札（戦闘仮画面）、施設の在庫・レシピ、出荷済みカードを共通デザインで表示。
- カードをクリック／タップまたは長押しで詳細画面。レシピ一覧の短押しは従来どおりレシピ設定、長押しは詳細。
- 詳細では左に必要素材・設備、中央にカード、右にステータスと効果。素材をタップして上流レシピへ移動、「戻る」で直前のカードへ。
- 攻撃・耐久・装填の強化マークと、強化後の数値表示を実装。基本能力は旧レシピ表の暫定数値を参照。実際の戦場バフとリアルタイムHPは戦闘画面実装後に連携。
- イラストは将来追加するため、カードの構成とデータを分離。
- 戦闘、CPU、オンライン対戦はまだ未実装です。


## v0.6 修正
- マスを42pxへ拡大（小画面では38px）。盤面はスクロールしてください。
- 仮配置を半透明表示し、向きをIN/OUTで明示。
- ✓を押して設置成功したら即座に建築モード解除。
- コンベアを太い橙色と方向矢印で描画。始点の選択も強調。
- ゲームの進行更新と画面更新の例外処理を分離。
- 描画や詳細UIのエラーでも時間更新が止まりにくい構造。
- 戦闘仮画面の手札描画は開いている間だけ更新。

注意：ブラウザで完全な操作試験は未実施。静的サーバーまたはGitHub Pages上で開いてください。
