# Factory Card Game v1.4 — 戦闘操作・補助カード拡張版

`index.html`を最新ブラウザで開くか、フォルダをGitHub Pagesに展開してください。既存の工場・物流も含まれます。

## 操作

- 手札の**ユニット**をドラッグして、味方の空き戦闘スロットへ放すと配置。クリック・タップだけならカード詳細を表示。
- 手札の**補助カード**を戦場の中央付近へドラッグして放すと使用を開始。対象指定が必要なら、その後、対象の戦闘スロットをクリック。選択取り消しボタンでキャンセル可能。明示的な補助カード専用の大きな発動エリアはありません。
- 失敗時や対応していない補助カードは手札を消費しません。

## 今回追加した戦闘側の効果

- 応急処置、集中砲撃、対装甲ロケット、対歩兵爆撃、制圧射撃、軽度EMP、煙幕、前線交代、再配置命令（指定2段階）、突貫工事。
- 従来の資材調達・緊急資材調達・大規模調達、19種のユニットの既存基本戦闘効果と簡易CPUは継続。
- HPが0になったユニットの撤去猶予と、バフの効果時間を継続管理。

## まだ未実装・限定的な部分

- 緊急搬送の倉庫カード選択UI、生産加速の施設指定UI、CPUの工場建設・在庫・生産・手札の実体が必要な偵察カード、設備再利用。使用を試みてもカードは消費しません。
- 準備・戦闘の厳密な同時解決や、敵CPUの戦術、いくつかの効果の端数・適用タイミングは追加検証が必要です。
- ブラウザでの実機ドラッグ検証は未実施です。コード・エンジンテストと同等の保証ではありません。
