# Factory Card Game v1.7 仕様監査・不具合修正版

v1.6をもとに、素材カード消費・自壊・準備時間中の妨害禁止・隣接範囲・一部戦闘判定を修正しました。既存の工場、ベルト、倉庫、強化モジュール、戦闘UIは維持します。

- 起動：`index.html` を静的Webサーバー経由で開く。GitHub Pages で利用できます。
- テスト：Node.jsで `node test_v17_audit.mjs` などを実行。
- 検証・残項目：`AUDIT_REPORT.md` を参照。
- `test_engine.mjs` は過去版の仕様を前提とした古い回帰テストです。独立強化モジュールの現行テストは `test_v16.mjs` です。

戦闘盤面の自軍ユニットをクリックするとカード詳細に自壊ボタンが表示されます。自壊には確認ダイアログがあります。


## v1.8 カードUI更新

- タップでプレビュー、右欄で素材確認、確定ボタンで初めて生産レシピ変更
- 長押しで従来のカード詳細を表示、工場側の自動生産モードは継続
- 戦場ユニットに薄い円形リロードリングを追加（％表示なし）
