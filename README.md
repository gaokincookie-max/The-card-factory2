# FACTORY CARD GAME — v1.0 工場操作 UI 改修

GitHub Pages で公開可能な静的 Web ゲーム試作版です。`index.html` をブラウザで開くか、GitHub Pages にファイル一式を公開してください。

## 操作

- 下部ビルドメニューで建物を選択 → 盤面をタップ → ✓で確定・↻で回転・×で中止
- 下部「ベルトモード」を押すとベルト敷設モードに切り替わり、再度押すと終了
- 始点・終点の2タップで直線ベルト。施設のマスを始点または終点に指定すると、施設の外周で接続。方向が合わない場合は設置しない
- 既存ベルトをタップすると接続・削除。ダブルタップでも削除（アイテム消失）
- 施設をタップすると詳細。加工系はレシピ（選択中・全素材あり・一部素材あり・素材なしの順）、在庫、円形進捗。採集・倉庫・強化モジュールは種類別に情報を表示
- 右上の出荷区画設定では2×2の境界を選択
