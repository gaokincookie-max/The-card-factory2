# FACTORY CARD GAME — 工場フェーズ実装 v0.3 / Phase 1+

GitHub Pagesにアップロード可能な、外部依存のない静的Webアプリです。**CPU対戦の完成版ではありません。**

## 起動
VS CodeのLive Server、または `python -m http.server 8000` をこのフォルダ内で実行し、http://localhost:8000/ を開いてください。GitHub Pagesではリポジトリのルートを公開してください。

## 操作
- 施設プルダウン → 盤面クリックで建設。採集機は緑色の2×2ゾーンに重ねてください。
- 「回転 R」で施設の入出力方向を切り替え。初期向きでは右側が出力、左側が入力です。
- 「ベルト敷設」→ 始点と終点の2クリックで直線設置。施設・資源ゾーンは通過できません。
- 「在庫・レシピ確認」→ 加工炉または組立加工機をクリック → レシピを選択。
- 「撤去モード」→ 施設・ベルトをクリックで撤去。
- 試験例：左上資源ゾーン(4,4)に鉄鉱石採集を設置 → (12,4)に加工炉を設置 → (6,4)から(11,4)へベルトを接続。加工炉の在庫に鉄鉱石が入ります。加工炉の出力は右側なので、(13,4)以東に出力用ベルトを敷設してください。

## 現段階で動くもの
32×32暫定工場グリッド、採集ゾーン4つと採集機4種、建設資材、建設撤去、単純な直線ベルト搬送、採集アイテム生成、加工炉の8レシピ、組立加工機の5レシピ、自動レシピ初回選択、手動レシピ変更、入力在庫、出力待ち。

## 未実装・制限
戦闘・CPU・オンライン・カード製造・倉庫・中央出荷・強化モジュールの実稼働は未実装です。分流／合流の交互処理は経路情報の土台のみで、複雑な合流の公平性や保存・復帰は未検証です。単純生産レシピ時間・建設費・資源生産速度は暫定値です。

## 設計
`src/engine.js` は描画に依存しない状態・操作・時間進行。`src/app.js` はDOM/UI。`data/cards.json` は将来のカード定義。この分離によりCPU・通信・カード追加を段階的に拡張できます。GitHub Pagesは静的公開のみで、オンライン対戦には別途サーバーが必要です。
