# Factory Card Game v1.3 – 戦闘基盤

工業画面v1.2の機能を維持し、5列×前後2段の戦闘画面、手札からのユニット配置、準備時間120秒、通常攻撃、リロード時間の進行、HP、死亡後10秒の撤去待ち、簡易CPU配置を追加。

## 操作
工場からカードを出荷し、上部の戦闘画面ボタンで切り替える。手札からユニットの「配置を選ぶ」を押し、味方の空きスロットを選択する。カードを長押しすると詳細。

## 未実装・制限
- CPUは定型的にユニットを配置する検証用。工場構築AIではない。
- 補助カードは仮の破棄操作。効果は未実装。
- 支援効果は補給班・野戦指揮官・防衛指揮車・電子戦車両・回復の一部を実装。全特殊能力・対象指定・アニメーションは未完成。
- オンライン対戦、セーブ、3D未実装。
- ブラウザでの実機確認は別途必要。
