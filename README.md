# Factory Card Game v1.6 — HUD / facility refactor

GitHub Pagesなどの静的ホスティングに置いて遊ぶ Web ゲーム試作版です。`index.html` をHTTPサーバー経由で開いてください。ブラウザでファイルを直接開いた場合、JSONの取得が制限される可能性があります。

## v1.6 主な変更
- ヘッダーは自軍HP・自軍2×5配置・敵軍2×5配置・敵軍HPの横並び。工場画面でも戦闘状態を直接参照し、HP・配置・撤去待ちを更新。スマホ横画面向けに高さを削減。
- カード詳細の能力は HP・攻撃力・リロード時間の3つ。装填強化の表示は `基本リロード時間 / 1.2` へ変換。
- 攻撃・耐久・装填強化モジュールは、ベルトへ重ねず空きマスに設置。入力側のベルトからカードを受け取り、1秒加工し、背面側のベルトへ出力。ユニットのみ対応する強化が付く（同種強化を重ねない）。既存のカード強化マークは維持。
- 強化モジュール詳細：左に強化説明、右に入力カード→強化後カードと円形進捗ゲージ。
- 倉庫詳細：左にカード在庫、右にランダム・タグ指定・カード名指定の3操作と次の出荷までの進捗ゲージ。タグ選択、倉庫内カード名選択はダイアログ内の選択パネルから行う。
- 上部HUD・進捗ゲージは全盤面の再生成とは独立して更新。

## 注意点
- v1.6は従来の「ベルト上に設置する強化モジュール」と互換でないため、テストも新仕様に更新しました。
- 実ブラウザでの全操作検証は実行環境のアクセス制限で完了していません。コード構文とエンジンテストを実施済みです。
- CPUは引き続き試験用簡易CPUで、敵工場と偵察カードは未完成です。
