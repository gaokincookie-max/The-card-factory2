# Factory Card Game — Phase 3 / Logistics & Upgrade Alpha

企画書v0.3に基づく工業画面の検証版。`index.html`を静的ホスティング（GitHub Pagesなど）へ配置して起動します。ローカルで試す場合は `python -m http.server 8000` の後、http://localhost:8000 から開くとES moduleが確実に読み込めます。

## 実装した部分
- 採集ゾーン・採集設備、加工炉・組立加工機、4系統のカード工場
- ベルト直線敷設、端点からの接続、途中接続による分流・合流、合流の交互受け入れ（交差禁止）
- 倉庫の通常排出・名前指定・タグ仕分け、アイテム個数比例のランダム抽選
- 中央2×2出荷と手札8スロットの対応、統合・左右/上下分割・1+3・4分割
- ベルト上の攻撃・耐久・装填強化モジュール（各種類は1カードにつき一回付与）
- ユニット以外のアイテムは強化せず通過、強化情報を倉庫/出荷まで保持
- 戦闘画面（仮）でのみ手札を表示

## 現在の制限
- 戦闘、CPU、オンライン、補助カード使用、偵察カード、カードの戦闘ステータス反映は未実装です。
- 装備済み強化が与える戦闘上の効果は未実装です（カード属性の付与のみ）。
- 仕分けやベルトの複雑な混雑・同時搬送について、全組み合わせのブラウザ統合テストはまだ行っていません。
- 倉庫の出口速度や変更クールタイム、強化時間・建設費などはテスト用暫定値です。
- 出荷区画は予め用意された代表的な分割プリセットです。2×2のすべての分割パターンを編集するUIは今後追加予定です。
- エンジンの実装は引き続きプロトタイプ段階です。CPUやオンラインを追加する前に、決定論的なシミュレーション・乱数管理・テスト基盤を強化する必要があります。

## 内部テスト
`node test_engine.mjs` で採集施設配置、分岐合流、モジュールの強化、区画容量、満杯時の拒否を検査できます。
