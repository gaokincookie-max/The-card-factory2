# Factory Card Game v1.5 — 戦闘補完・軽量化

`index.html` を開くか、全ファイルを同じ構成で GitHub Pages に配置してください。工場および戦闘UIを含みます。

## 主な変更

- **ラグ対策**：戦闘画面の表示中は工場盤面全体の定期再描画を止め、表示中の画面だけ再描画します（工場と戦闘のシミュレーションは両方継続）。工場描画は約350ms間隔、戦闘は約200ms間隔。工場の各マスも表示に変化がない場合はDOMの作り直しをスキップし、戦闘各マスも表示内容が同じ場合はHTMLを書き換えません。ゲーム進行の50msタイマーはそのままです。
- **緊急搬送**：補助カードを戦場へドラッグすると倉庫とアイテムを選択する一覧が表示されます。手札の空きがない場合は発動せずカードを消費しません。倉庫から搬送したカードには元の強化情報が残ります。
- **生産加速**：戦場へドラッグ後、加工炉・組立加工機・カード工場・強化モジュールから対象を選択。対象の処理速度を12秒間+50%。採集施設と倉庫は対象外です。
- **衛生兵**：HP最小が同数の場合の対象選択をランダムに変更。
- v1.4のユニット配置ドラッグ、通常攻撃、補助カード効果、工場・物流機能を維持。

## 残る未完成・検証事項

- 偵察系カード5種類には敵工場・倉庫・手札の実データが必要です。現在の簡易CPUは工場を持たないため未実装のままです。未対応カードは消費されません。
- 「設備再利用」「過負荷運転」は初期採用対象外／保留のため、新たな効果は割り当てていません。
- 戦闘の厳密な同時解決、支援効果の同時刻境界、CPU戦術の品質はさらに検証が必要です。
- 実ブラウザ（特にスマホのドラッグや長時間負荷）の操作検証は未実施です。負荷はブラウザ・端末・建設密度によって異なります。
