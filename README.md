# Factory Card Game v1.2 — Logistics UX

v1.0 をベースに、以下のUIを改善しました。

- **生産ゲージ**：施設詳細を開いたまま約50ms間隔のシミュレーション更新に連動し、進捗率・残り時間・素材在庫・停止表示が更新されます。ポップアップ全体は再描画せず、現在表示中の値だけを変更します。
- **ベルト操作**：建築カテゴリと独立した「↳ ベルト敷設」切替を建築ドック上部に配置。もう一度押すと解除し、建築施設の選択でも自動解除します。収納時は切替も非表示です。
- **分流・合流の表示**：ベルトの接続数から分流・合流の状態を判定。「分」または「合」、入力の青い矢印と出力の橙色矢印をマス上に表示します。搬送中のカードは小さな点で示します。

## 操作

1. 下の「↳ ベルト敷設」を押して始点・終点を選択します。ボタンをもう一度押すと解除します。
2. 既存ベルトに接続すると、その接続数に応じて分流・合流マーカーが表示されます。
3. 加工施設をタップして詳細を開くと、円形ゲージと素材数が時間経過に沿って更新されます。

## 検証

Node.jsでエンジンテスト、既存回帰テスト、UIコード検査、構文検査を実施しました。実ブラウザ・スマホ実機での全操作と長時間稼働は未検証です。

GitHub Pages対応の静的ファイル構成です。`index.html` と `src/`, `data/` を同じ相対構造のまま公開してください。

- **出荷区画**：右上の重複した設定ボタンを削除。盤面中央の出荷マスをタップして編集します。
