- Rebind the open facility panel by stable building ID when the authoritative server sends a new factory snapshot. Server snapshots replace building objects, so the original panel previously read stale objects.
- Immediately refresh live production gauge and inventory counters on server view updates, using shared UI for offline and online.
- Refresh recipe list and right-side detail when the server-confirmed recipe or production mode changes; retain recipe preview and left scroll position across server ticks.
- Refresh warehouse mode detail and inventory tab after server updates.
