# v4.0 — Full-screen online room and match result

- Full-screen online entry, lobby, start animation and result (no dismiss-to-factory from lobby).
- Deployment server auto chooses localhost when loaded from localhost/127.0.0.1, otherwise Render WSS; URL is public and not a secret.
- Authoritative result: HQ defeat and simultaneous draw; explicit opponent departure means win; accidental disconnect pauses for 90s, then win on expiration.
- On result, each remaining player presses «対戦ロビーへ戻る». Once all connected participants returned, the same room resets game state and ready flags, then can rematch.
- No persistent match history, currency or cosmetic rewards yet. Concurrent render deployments and server restarts clear in-memory sessions.
- End-to-end browser/Render two-device verification still needed.
