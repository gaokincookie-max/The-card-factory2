# v4.8.9 — final cleanup and dependency audit

## Changes applied
- Removed the obsolete no-op `placement()` function and its two calls; the real floating build toolbar remains untouched.
- Removed an empty `pointerup` handler from each factory cell. This does not affect pointer interaction.
- Added `tests/project-integrity.test.mjs` to check local static module dependencies, HTML assets, CSS inclusion order and obsolete-code regression.
- Updated version strings and refreshed developer guidance.

## Risk control
- No change to battle, factory rules, network protocol, data, CSS, 2D/3D drawing or virtual landscape.
- The game still requires live browser regression checks for iPhone Safari and WebGL; Node tests cannot prove pixel-perfect equivalence.

## Further candidates **not removed**
- Older 2D and fallback selectors: still potentially needed when WebGL is unavailable.
- Historical docs/test scripts: useful as compatibility references until all paths are documented.
- Display-name based battle-effect dispatch: changing serialization requires migration design.

## Recommended regression smoke test
1. Open game in desktop and smartphone portrait (physically rotate phone, keep portrait lock).
2. Open and close dock, build facilities, set a recipe, inspect stock.
3. Switch 2D/3D, drag cards, verify selection after rotating screen.
4. Connect to an online room and confirm commands and state updates.
