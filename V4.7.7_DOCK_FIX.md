# v4.7.7 portrait-rotation builder menu fix

On portrait iPhones the entire game body is CSS-rotated into a virtual landscape viewport. Safari can position `fixed` drawers against the visual rather than transformed layout viewport. The builder menu now uses `position:absolute` anchored to the rotated body, with independent scrollable tabs/cards and a preserved collapse handle. Physical landscape and desktop CSS remain unchanged.

Verify on iPhone Safari: portrait-held factory screen, builder tabs and all categories, opening/closing drawer, factory zoom/pan, switching factory/battle, physical landscape. Device testing pending.
