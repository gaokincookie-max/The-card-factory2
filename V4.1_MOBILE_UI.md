# v4.1 Smartphone landscape usability pass

- Preserved shared game engine, command transport and desktop gameplay.
- Added `src/mobile-board-controls.js`: coarse-pointer landscape mode only. One touch drags scroll viewport; two pointers zoom the 32x32 board within 0.55x to 2.2x. Prevents accidental cell clicks after gestures. Browser zoom support is needed (`CSS zoom`).
- Slimmed top HUD, build dock, floating build controls and board chrome on touch landscape screens of height <= 700px.
- Made facility dialog fit landscape height with internal scrolling. No change to recipe confirmation semantics.
- Preserved fixed top combat/factory switch and existing 2x5 HUD.

## Validation
`npm run check` and `npm test` pass, including online and rematch tests. Browser/iPhone/Android touch interaction and device-specific layouts **not tested**. Zoom may need further corrections for pointer capture, selection gesture thresholds and Safari viewport behavior after actual device testing.
